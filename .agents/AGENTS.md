# Project Behavioral Rules & Guidelines

1. **NO EMOJIS ANYWHERE IN THE APP**:
   - Do NOT use unicode emojis (e.g. 👋, 🎉, 🚀, 📋, 🏠, 👥, 💳, 👤, ⚠️, 📅) anywhere in the application code, UI text, or notifications.
   - Use clean Lucide SVG icons instead (or standard text).

2. **NEVER USE LUCIDE SPARKLES**:
   - Do NOT use the `Sparkles` icon from lucide-react. Use clean functional icons (e.g., `Building2`, `Users`, `CreditCard`, `Wrench`, `CheckCircle2`, `AlertTriangle`).
